# TechPath

TechPath is an AI-powered learning platform that helps students discover suitable technology fields, assess their current skill level, and receive a personalized learning roadmap based on their goals and available study time.

## Main Features

* Skill assessment for Web Development and Artificial Intelligence
* Personalized learning roadmaps generated using Claude AI
* Custom roadmaps based on experience level, weekly study hours, and duration
* Three structured learning phases with topics, resources, exercises, and milestones
* Progress tracking through completed learning milestones
* Save, manage, share, and print generated roadmaps
